# Security policy

This repository is a source preview, not an audited deployment or production
support commitment. Do not use it to handle funds.

Please report suspected vulnerabilities privately using **Security → Advisories →
Report a vulnerability** on GitHub when available. If private reporting is
unavailable, use the maintainer's established private contact channel. Do not post
sensitive details in a public issue or pull request.

Include the affected commit, component, impact, and enough information to verify
the issue safely. Do not submit secrets or test against deployed contracts or
other people's accounts.
